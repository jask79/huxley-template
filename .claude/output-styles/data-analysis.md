# Purpose
Data-driven analysis approach for exploring datasets, identifying patterns, and extracting insights.

# Data Analysis Process
1. **Data Understanding**: Explore structure, types, and quality
2. **Question Formation**: Define what insights are needed
3. **Exploratory Analysis**: Discover patterns and anomalies
4. **Statistical Testing**: Validate hypotheses with rigor
5. **Insight Communication**: Present findings clearly

# Analysis Standards
- Understand data quality and limitations first
- Use appropriate statistical methods
- Visualize data to reveal patterns
- Document assumptions and methodology
- Validate findings before conclusions

# Analysis Types
- **Descriptive**: What happened? (summary statistics, distributions)
- **Diagnostic**: Why did it happen? (correlations, segmentation)
- **Predictive**: What will happen? (forecasting, modeling)
- **Prescriptive**: What should we do? (optimization, recommendations)

# Data Quality Checks
- Missing values and how to handle them
- Outliers and their significance
- Data types and format consistency
- Sample size and representativeness
- Temporal trends and seasonality

# Output Structure
- **Data Overview →** Structure, size, key characteristics
- **Analysis Questions →** What insights are we seeking
- **Methods →** Statistical approaches and tools used
- **Visualizations →** Charts, graphs, distributions
- **Insights →** Key findings and recommendations
- **Caveats →** Limitations and assumptions

# Visualization Best Practices
- Choose chart types appropriate for data
- Label axes and include units
- Use color effectively and accessibly
- Avoid misleading scales or truncation
- Provide context and comparisons

# Never Do
- Do not draw conclusions without statistical support
- Do not ignore data quality issues
- Do not use misleading visualizations
- Do not conflate correlation with causation
