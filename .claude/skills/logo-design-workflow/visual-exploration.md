# Visual Exploration Skill

**Agent:** 🎨 Graphic Designer
**Phase:** Develop (Double Diamond)
**Purpose:** Generate and iterate on visual concepts based on strategic foundation

---

## Skill Overview

This skill guides the divergent visual exploration phase of logo design. Working from the Brand Specialist's strategic foundation, generate multiple distinct concepts and iterate toward the strongest direction.

**This is NOT one-shot generation.** It's structured visual exploration with:
- Multiple concept directions
- Iterative refinement rounds
- Rationale for every design decision
- Stakeholder feedback integration

---

## Prerequisites

Before beginning visual exploration, confirm you have:

- [ ] Discovery brief from Brand Specialist
- [ ] Brand archetype and positioning
- [ ] Approved creative direction moodboard(s)
- [ ] Clear success criteria
- [ ] Stakeholder approval to proceed

**If any of these are missing, request them before starting visual work.**

## Phase: DEVELOP (Divergent Visual Exploration)

### Stage 1: Concept Generation

**Generate 3-5 distinct visual directions.** Each should be:
- Strategically grounded (connects to brand archetype/positioning)
- Visually distinct (not variations, but different approaches)
- Defensible (clear rationale for every choice)

#### Concept Development Framework

For each concept, develop:

```markdown
## Concept [A/B/C/D/E]: [Concept Name]

### Strategic Connection
How this concept expresses the brand archetype and positioning:
- [Connection to archetype]
- [Connection to positioning]
- [Connection to target audience]

### Visual Approach

#### Mark Type
- [ ] Wordmark (typography only)
- [ ] Lettermark (initials)
- [ ] Symbol/Icon (standalone mark)
- [ ] Combination (symbol + wordmark)
- [ ] Emblem (text inside symbol)

#### Form Language
- **Geometric vs. Organic:** [choice + why]
- **Angular vs. Curved:** [choice + why]
- **Open vs. Closed:** [choice + why]
- **Simple vs. Complex:** [choice + why]

#### Typography
- **Font Family/Style:** [specific choice]
- **Weight:** [light/regular/medium/bold/black]
- **Treatment:** [caps/lowercase/mixed, spacing]
- **Character:** [what personality it conveys]

#### Color
- **Primary Palette:** [3-5 colors with hex]
- **Color Strategy:** [why these colors work together]
- **Emotional Impact:** [what the palette conveys]
- **Functional Considerations:** [contrast, accessibility, reproduction]

### Visual Presentation
[The actual logo concept - described or generated via AI image tool]

### Rationale
**Why this concept works:**
1. [Reason 1 - tied to strategy]
2. [Reason 2 - tied to audience]
3. [Reason 3 - tied to differentiation]

**Potential concerns:**
1. [Concern and mitigation]
2. [Concern and mitigation]

### Applications Preview
How this concept performs across key touchpoints:
- **Favicon/App Icon:** [assessment]
- **Website Header:** [assessment]
- **Business Card:** [assessment]
- **Large Format:** [assessment]
```

## Design Principles to Apply

### Quality Standards

**Reject Generic Choices:**
- No obvious clip-art symbols
- No overused font combinations
- No cliché color palettes for the industry
- Every element should have a "why"

**Embrace Purposeful Decisions:**
- Typography that expresses personality
- Colors that create emotional response
- Forms that communicate brand attributes
- Negative space used intentionally

### Technical Requirements

**Scalability:**
- Works at 16x16 favicon
- Works at billboard scale
- Details remain clear at all sizes

**Versatility:**
- Single color version exists
- Reversed (light on dark) version works
- Horizontal and stacked orientations possible

**Reproduction:**
- Clean vector paths
- No overly complex gradients (unless intentional)
- Works in print and digital

### Iteration Discipline

**Each iteration should:**
1. Address specific feedback
2. Maintain strategic alignment
3. Improve on previous version
4. Document what changed and why

**Avoid iteration traps:**
- Don't abandon good elements without reason
- Don't drift from strategic foundation
- Don't over-refine before direction is approved
- Don't add complexity to "impress"

## Visual Generation Tools

### AI Image Generation (via Bifrost Gateway)

When generating visual concepts:

**Effective Prompts:**
- Reference specific design styles (Swiss design, Bauhaus, contemporary minimal)
- Describe form language (geometric, organic, angular)
- Specify technical requirements (vector-friendly, simple forms)
- Include brand attributes as modifiers

**Prompt Pattern:**
```
Logo design for [brand name], [brand attributes],
[mark type] style, [form language],
[color palette description],
[style reference], professional quality,
simple vector-friendly forms
```

**Iteration Pattern:**
```
Variation of [previous concept],
[specific change: e.g., "more geometric", "bolder typography"],
maintaining [elements to keep],
[additional refinements]
```

### Manual Design Guidance

If working with vector tools or describing to a human designer:

- Provide grid/proportion specifications
- Document exact color values (hex, RGB, CMYK)
- Specify font names and weights
- Include spacing and sizing ratios

## Anti-Patterns to Avoid

**Concept Generation:**
- Starting with visuals before understanding strategy
- Generating "what looks cool" without rationale
- Only creating variations of one idea
- Ignoring technical requirements

**Presentation:**
- Showing visuals without context
- No comparative analysis
- Not recommending a direction
- Too many concepts (decision paralysis)

**Iteration:**
- Changing direction without stakeholder input
- Abandoning good elements without reason
- Over-refining before approval
- Not documenting changes

**Handoff:**
- Incomplete specifications
- Missing file formats
- No strategic context for UI Designer
- Assumption that "they'll figure it out"
